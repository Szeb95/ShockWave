ShockWave Avatar Panel

Add the avatar tools to VRChat Creator Companion. Use touch or either hand to point at your toys, patterns and shocker controls.

Add to Creator Companion

If the button does not open VCC, add this repository in Settings → Packages → Add Repository:

https://szeb95.github.io/ShockWave/index.json

  1. Add the official VRCFury repository if it is not already available.
  2. Open Manage Project in VCC and add ShockWave Avatar Panel. It requires the VRChat Avatars SDK and VRCFury.
  3. In Unity open Tools → ShockWave → Panel. Choose your avatar and menu path, then explicitly add or update the panel.
  4. Upload the avatar when ready. In VRChat use Show panel in your chosen menu. The panel starts hidden and the size defaults to 20%.

VCC updates the Editor tools. Existing avatars need an explicit Update Toy Control on Avatar and upload to receive panel changes. Updating the Windows app does not edit your Unity project.

The package migrates only the old Assets/Editor/SzebsToysToyControl tool folder. Generated content under Assets/SzebsToys stays in place.
