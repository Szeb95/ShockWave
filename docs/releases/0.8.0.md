# ShockWave 0.8.0 — integrated SteamVR controls

The wrist menu and floating panel now run inside the Windows app. Start SteamVR,
open Toy control or Shocker control and press the headset icon. No Unity project,
avatar installation or avatar upload is needed for this panel.

- Compact wrist menu with proximity-revealed grip handle and pull-to-open/close.
- Larger transparent panel with side grip handles; use the free hand's pointer,
  or grip both sides and pull apart/together to resize.
- Shared desktop/VR toy selection, curve input, recording and looping. A held
  drawing continues beyond the grid until trigger/mouse release.
- Shocker view with intensity/duration, two-press confirmation within three
  seconds and timed display of the submitted capped strength.
- Settings for hand, Wrist/Panel startup, automatic VR opening, saved wrist fit
  and whole-overlay transparency; Open in VR, Recenter and Stop on both pages.
- Stable SteamVR input files outside versioned app folders, verified physical
  paths and explicit setup errors. Six default controller profiles are included.
- The desktop retains the classic layout with native drawing. Retired desktop
  shader rendering/demo listeners are excluded from production; active OSC/SPS
  and optional existing avatar support remain.
- README and previews now lead with integrated SteamVR setup. Source builds
  download the pinned OpenVR library and verify its checksum and license.

## Install or update

Download `ShockWave-0.8.0-win-x64.zip`, extract the whole archive into a new folder
and run `ShockWave.exe`. Keep all files together. Node, .NET and the Bluetooth
engine are included. **Install this version manually once when coming from
0.7.x:** older updaters reject the added SteamVR files. This version updates the
validator for future SteamVR packages. The old updater may display the release,
but it cannot complete that first download/install.
Existing settings and protected credentials stay in the user-data folder.

Close older ShockWave/standalone test apps before opening the new version. Start
SteamVR separately. For a silent toy, check **Settings → Debug → Test mode**:
Test mode allows preview but blocks physical commands. To use hardware, turn it
off, save/confirm Live mode, select a connected function and draw again. Each
owner's Sensitivity and Max % still apply.

Closing the wrist menu preserves active patterns and already submitted shocks.
Stop ends continuous toy activity and cancels pending confirmation; a shocker
command already accepted by its provider can run for its bounded duration.

## Verification and limits

The exact package and an isolated copy with no shader/hardware files each pass
171 integrated checks using simulated devices. The clean-source panel also passes
171 checks, updater fixtures pass 71 and bridge/peer tests pass 67. Packaged
Bluetooth/remote-worker checks pass. A clean source build verifies the pinned
OpenVR download. The publication record contains ZIP and hosted-check evidence.

The prior live passive input check verified pointer poses, triggers and grips on
Oculus Touch with unchanged game focus. Headset ergonomics and physical-device
output/Stop timing still need device-specific testing. Friends Connect passed
pairing/save/restart/reconnect checks with two simulated clients on one PC;
separate-network reachability remains unverified. There is no TURN relay fallback.
The Windows app is unsigned. This release does not update or save Unity avatars.
